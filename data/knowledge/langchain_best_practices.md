# LangChain Agent 开发最佳实践

## Tool 设计原则

1. **单一职责**: 每个 Tool 只做一件事
2. **清晰描述**: docstring 必须包含功能说明和参数说明
3. **错误友好**: 返回错误信息而非抛异常
4. **输入验证**: 对参数做基本校验

## Agent Prompts 技巧

### System Prompt 结构
```
1. 角色定义 - 你是什么
2. 工作流程 - 怎么做 (步骤)
3. 输出格式 - 输出什么
4. 约束规则 - 不能做什么
```

### 示例: Researcher Agent
```
角色: 研究分析师
流程: 检索知识库 → 阅读文档 → 分析 → 结论
输出: 结构化分析报告
规则: 不凭空猜测，引用来源
```

## RAG 优化策略

1. **分块大小**: 600 字符适合中文段落
2. **重叠窗口**: 80 字符保留上下文连续性
3. **检索数量**: Top-5 平衡准确性和 Token 消耗
4. **元数据过滤**: 按 source、type 筛选

## 多 Agent 协作模式

- **顺序 Pipeline**: A → B → C，每个 Agent 顺序执行
- **路由模式**: 根据任务类型自动选择最合适的 Agent
- **辩论模式**: 多个 Agent 对同一问题给出不同观点，汇总择优

## 性能优化

- 使用 async/await 非阻塞 IO
- LLM 调用添加超时控制
- 向量检索结果缓存
- 请求限流保护
